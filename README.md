# LoanVision – Loan Portfolio Analytics Dashboard

## About the Project
LoanVision is an interactive Loan Portfolio Analytics Dashboard built using **FloNeo**, an AI-powered app-building platform. It is designed to present loan portfolio information, customer details, and financial risk through a simple and user-friendly interface.

## Features
- **Overview:** Displays key loan portfolio metrics.
- **Loan Analysis:** Provides insights into loan information.
- **Customer Analysis:** Organizes customer-related information.
- **Risk Analysis:** Helps explore loan risk indicators.
- **Loan Records:** Provides access to loan records.

## Tools & Platform
- FloNeo – AI-powered app building
- Dashboard design and data visualization

## Live Demo
[View LoanVision Dashboard](https://floneo.app/published/loanvision-dashboard)

The purpose of this project was to explore AI-powered application development and build a functional dashboard for exploring loan portfolio information.
